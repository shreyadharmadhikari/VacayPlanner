# VacayPlanner – Travel Planning Web Application

VacayPlanner is a responsive frontend web application designed to help users explore destinations, discover key travel information, and generate simple itineraries. The project demonstrates strong fundamentals in JavaScript, API integration, and responsive UI design.

---

## Live Demo

https://shreya-vacayplanner.netlify.app

---

## Overview

The application allows users to search for destinations across multiple categories and view curated travel insights, including attractions, weather conditions, and general information. It also includes a local favorites system for saving and revisiting destinations.

This project emphasizes clean UI, structured data handling, and a smooth user experience across devices.

---

## Features

### 1. Destination Search
- Search by **city, state, or country**
- Category-based filtering using dropdown selection
- Dynamic rendering of search results

### 2. Destination Insights
- Displays high-quality images of locations
- Highlights key tourist attractions
- Provides general information about the destination

### 3. Itinerary Generation
- Day-wise itinerary structure
- Clean and readable layout for planning trips

### 4. Favorites System
- Add/remove destinations using a toggle action
- Persistent storage using `localStorage`
- Quick access to saved destinations and itineraries

### 5. Explore Section
- Predefined popular destinations
- Card-based UI for easy browsing

  - DOM manipulation
  - Async/await for API handling

---

## APIs Used

- **Weather API** – Fetches real-time weather data  
- **REST Countries API** – Provides country-level details  
- **Wikipedia API** – Retrieves general information and facts  
- **Pexels API** – Supplies high-quality destination images  

---

## Key Implementation Highlights

- Mobile-first design ensuring usability across all screen sizes  
- Fully responsive layout (mobile, tablet, desktop)  
- Asynchronous data handling using `async/await`  
- State management using browser `localStorage`  
- Modular and maintainable JavaScript structure  
- Multi-page navigation flow (Search → Results → Itinerary → Favorites)
